# homebrew-tap

Personal Homebrew tap.

```bash
brew tap leifsternyc/tap
brew trust leifsternyc/tap
brew install --cask aerialwall
```

| Cask | Description |
| --- | --- |
| [`aerialwall`](Casks/aerialwall.rb) | [AerialWall](https://github.com/LeifsterNYC/AerialWall) — Apple's aerial screen savers as live desktop wallpapers |
